# Jose Mari M. Ramirez — Portfolio

Personal portfolio for Jose Mari M. Ramirez, a junior web developer focused on Shopify, WordPress, JavaScript, and React.

This site is a React + JavaScript (Vite) rebuild of the original static HTML portfolio. Client project work on Shopify, WordPress, OctoberCMS, and Laravel is preserved as originally described.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Live site

Deployed with GitHub Pages from the `main` branch:

https://jm-Ramirez7.github.io/portfolio-v2/
